# Stock Sentinel
### Supermarket Inventory & Expiry Monitoring System

**Stock Sentinel** is a console-based inventory management system developed in C to help supermarkets manage their products, monitor stock levels, and track product expiry dates.

The system uses a product and batch-based approach to maintain inventory records. Each product can have multiple batches with individual quantities and expiry dates, making it easier to monitor stock and identify expired or near-expiry products.

### Key Features

- **Product Management:** Add, view, search, update and delete product records.
- **Batch Management:** Maintain multiple batches for each product with separate quantities and expiry dates.
- **Expiry Monitoring:** Identify expired and near-expiry batches.
- **Stock Management:** Track available stock quantities.
- **Low-Stock Alerts:** Identify products whose stock falls below their minimum stock level.
- **FEFO Recommendations:** Prioritize batches with earlier expiry dates (First Expired, First Out).

### Technologies Used

- **Programming Language:** C
- **Concepts:** Structures, arrays, functions, pointers, modular programming and file handling.
- **Interface:** Command-line / Terminal-based application.

### Project Objective

To develop a simple and efficient inventory management system that helps supermarkets organize stock, monitor product expiry dates, and reduce losses caused by expired products.
